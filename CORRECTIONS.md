# Corrections and versions

Version 0.1.0 is the first standalone edition of this paper. It cites the earlier weighing-matrix transfer and the two conference-based constructions of order 7516.

Please report corrections through the repository issue tracker with the affected version, statement or input, and a reproducible calculation or source. A verified earlier construction warrants a dated attribution update. A mathematical error warrants a correction or withdrawal identifying the affected orders. A replacement release will identify the version it supersedes. Archived versions retain their original contents.
